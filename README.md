# Руль как геймпад (wheel2pad)

Программа превращает руль **Artplays V-1200 Vibro** в обычный геймпад Xbox 360.
Игры (например, **Forza Horizon 4**) думают, что подключён геймпад, поэтому
в настройках игры ничего менять не нужно.

Это папка **для разработчика**. Тому, кто просто играет, отдаётся готовая папка
с `wheel2pad.exe` — Python ему не нужен (см. «Сборка exe»).

## Сборка exe (для того, кто будет играть)

**Способ 1 — на своём компьютере (Windows):**
1. Один раз запустите `start.bat` — он поставит Python и зависимости.
2. Запустите `build_exe.bat`.
3. Отдайте архив `release\Wheel2Pad.zip`.

**Способ 2 — через GitHub Actions** (ничего ставить не нужно):
1. Залейте папку в репозиторий на GitHub.
2. Вкладка **Actions** → **Build wheel2pad.exe** → **Run workflow**
   (или запушьте тег вида `v1.0`).
3. Когда сборка закончится, скачайте артефакт **Wheel2Pad** внизу страницы запуска.

Внутри готовой папки:

| Файл | Зачем |
|---|---|
| `wheel2pad.exe` | Сама программа. Двойной щелчок — и работает |
| `ИНСТРУКЦИЯ.txt` | Пошаговая инструкция простым языком |
| `Перенастроить руль.bat` | Заново пройти калибровку |
| `Путь для HidHide.bat` | Копирует путь к exe для настройки HidHide |
| `wheel2pad.json` | Настройки руля — появится после первой калибровки |

Если драйвера ViGEmBus нет, exe сам предложит его установить: установщик
вшит внутрь (берётся из пакета `vgamepad`).

## Запуск без exe (через Python)

| Файл | Зачем |
|---|---|
| `start.bat` | Запуск. В первый раз ставит Python (через winget) и зависимости в `.venv` |
| `calibrate.bat` | Заново пройти калибровку |
| `hidhide_path.bat` | Копирует путь к реальному `python.exe` для HidHide |

## Что во что превращается

| На руле | Геймпад Xbox |
|---|---|
| Поворот руля | Левый стик, ось X |
| Газ / тормоз | RT / LT |
| Сцепление | Кнопка (по умолчанию LB) |
| Кнопки, лепестки, крестовина | Назначаются при калибровке |
| Вибрация из игры | На вибромотор руля (если руль её принимает) |

## Все файлы этой папки

| Файл | Зачем |
|---|---|
| `wheel2pad.py` | Программа: чтение руля (pygame-ce/SDL) → виртуальный Xbox 360 (vgamepad/ViGEmBus) |
| `requirements.txt` | Зависимости: `pygame-ce`, `vgamepad` |
| `start.bat`, `calibrate.bat`, `hidhide_path.bat` | Запуск через Python |
| `build_exe.bat` | Сборка exe через PyInstaller → `release\Wheel2Pad.zip` |

| `release_files\` | Что кладётся рядом с exe: инструкция и два bat-ярлыка |
| `README.md` | Этот файл |

## Флаги `wheel2pad.py` / `wheel2pad.exe`

`--calibrate` калибровка · `--show` значения в реальном времени ·
`--monitor` сырые оси/кнопки · `--list` устройства · `--where` путь для HidHide (копирует в буфер)

## Тонкая настройка (`wheel2pad.json` → `settings`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `steer_range` | 1.0 | Доля хода руля до полного стика (для 900° — 0.3–0.5) |
| `steer_deadzone` | 0.02 | Мёртвая зона в центре |
| `steer_anti_deadzone` | 0.0 | Компенсация мёртвой зоны игры (0.1–0.2, если мелкие повороты не доходят) |
| `steer_gamma` | 1.0 | >1 — мягче около центра |
| `pedal_deadzone` / `pedal_top_deadzone` | 0.04 / 0.03 | Гарантированные 0 % и 100 % педали |
| `clutch_button` | "LB" | Куда отправлять педаль сцепления, `""` — никуда |
| `rumble` | true | Передавать вибрацию на руль |

К одной кнопке Xbox можно привязать несколько кнопок руля — допишите их в список в `buttons`.

## Если антивирус ругается на exe

Exe-файлы, собранные PyInstaller в режиме `--onefile`, иногда ложно определяются
как подозрительные. Варианты: добавить папку в исключения Защитника или собрать
в режиме папки — заменить `--onefile` на `--onedir` в `build_exe.bat`
(тогда результат — папка `build\dist\wheel2pad\` с exe и папкой `_internal`;
поправьте строку `copy` в шаге 3/3, чтобы копировалась вся эта папка).
