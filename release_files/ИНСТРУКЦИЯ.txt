   ЧАСТЬ 1. Настройка — только ОДИН раз (~15 минут)
   ЧАСТЬ 2. Как играть — КАЖДЫЙ раз (1 минута)

=====================================================
   ЧАСТЬ 1. НАСТРОЙКА (один раз)
=====================================================

Перед началом:
   - руль подключён к компьютеру по USB
   - есть интернет (нужен только для HidHide в шаге 6)


-----------------------------------------------------
[ ] ШАГ 1. Распакуй папку
-----------------------------------------------------

   1. Найди архив Wheel2Pad.zip
   2. Правой кнопкой по нему -> "Извлечь все..."
   3. Нажми "Извлечь"

   ГОТОВО, если: открылась папка, и в ней есть
                 файл wheel2pad.exe

   !! Работай с РАСПАКОВАННОЙ папкой, не внутри архива.
   !! Не перемещай потом эту папку — иначе HidHide
      (шаг 6) перестанет её узнавать.


-----------------------------------------------------
[ ] ШАГ 2. Переключи руль
-----------------------------------------------------

   Если на руле есть переключатель угла 900 / 270 —
   поставь 270.

   Нет такого переключателя — пропусти шаг.


-----------------------------------------------------
[ ] ШАГ 3. Первый запуск
-----------------------------------------------------

   1. Двойной щелчок по wheel2pad.exe
   2. Откроется чёрное окно с текстом. Это нормально.

   !! Если вылезло синее окно "Windows защитила компьютер":
      -> нажми "Подробнее"
      -> нажми "Выполнить в любом случае"

   !! Если антивирус ругается на wheel2pad.exe —
      напиши Кириллу. Файл безопасный, но антивирусы
      иногда так реагируют на самодельные программы.

   ГОТОВО, если: в окне появилось "=== Калибровка ==="


-----------------------------------------------------
[ ] ШАГ 4. Настрой руль (калибровка)
-----------------------------------------------------

   ГЛАВНОЕ ПРАВИЛО:
   перед нажатием Enter щёлкни мышкой по чёрному окну.
   Иначе компьютер не поймёт, что ты нажала Enter.

   Окно будет задавать вопросы по очереди.
   Делай, что написано, потом жми Enter:

   1) Отпусти педали, руль ровно -> Enter
   2) Руль ДО КОНЦА влево, держи -> Enter
   3) Руль ДО КОНЦА вправо, держи -> Enter
      Верни руль ровно -> Enter
   4) Нажми ГАЗ до пола, отпусти -> Enter
   5) Нажми ТОРМОЗ до пола, отпусти -> Enter
   6) Сцепление: если есть педаль — нажми и отпусти.
      Если нет — просто Enter.

   Потом будут КНОПКИ.
   Окно пишет название кнопки — нажми кнопку на руле,
   которая будет её заменять.
   Не знаешь, что нажать? Жми Enter — кнопка пропустится.

   Советую так (для Forza Horizon 4):

      B ............ правый лепесток за рулём (передача вверх)
      X ............ левый лепесток за рулём (передача вниз)
      A ............ любая удобная кнопка (ручник)
      Y ............ любая кнопка (перемотка назад)
      START ........ любая кнопка (пауза / меню)
      DPAD_UP,
      DPAD_DOWN,
      DPAD_LEFT,
      DPAD_RIGHT ... крестик на руле: вверх, вниз, влево, вправо
      всё остальное  Enter (пропустить)

   !! Кнопку MODE на руле НЕ нажимай.

   ГОТОВО, если: написано "Готово, настройки сохранены"

   Потом окно попросит нажать Enter ещё раз —
   нажми, программа запустится.

   Ошиблась? Не страшно. Закрой окно,
   запусти "Перенастроить руль.bat" и пройди шаг 4 заново.


-----------------------------------------------------
[ ] ШАГ 4½. Если окно просит поставить драйвер
-----------------------------------------------------

   Только если в окне написано про ViGEmBus.
   Нет такого текста — пропусти.

   1. Нажми Enter
   2. Откроется установщик. Жми "Next" / "Install" / "Далее"
   3. Перезагрузи компьютер
   4. Снова запусти wheel2pad.exe

   Руль заново настраивать НЕ надо — настройки сохранились.


-----------------------------------------------------
[ ] ШАГ 5. Проверь, что работает
-----------------------------------------------------

   1. Чёрное окно НЕ закрывай.
      Там должно быть написано "Эмуляция запущена".
   2. Нажми на клавиатуре Win + R
      (Win — кнопка с окошком Windows)
   3. Напиши:  joy.cpl
   4. Нажми Enter
   5. В списке должен быть
      "Controller (XBOX 360 For Windows)"
   6. Выдели его -> "Свойства"
   7. Покрути руль, понажимай педали.

   ГОТОВО, если: крестик/полоски двигаются,
                 когда крутишь руль и жмёшь педали.

   Закрой это окошко.


-----------------------------------------------------
[ ] ШАГ 6. Спрячь настоящий руль от игры (HidHide)
-----------------------------------------------------

   Зачем: иначе игра видит руль ДВА раза
   и машина дёргается.

   Шаг длинный. Не спеши. Тут 3 маленьких части.

   --- 6а. Установить ---

   1. Открой в браузере:
      github.com/nefarius/HidHide/releases
   2. Скачай файл, который называется примерно так:
      HidHide_1.5.230_x64.exe
      (цифры могут быть другие — это нормально)
   3. Запусти его, жми "Next" / "Install"
   4. Перезагрузи компьютер

   --- 6б. Разрешить нашей программе видеть руль ---

   1. В папке двойной щелчок по "Путь для HidHide.bat"
      Он покажет путь и сам его скопирует.
   2. Открой меню Пуск, найди и запусти
      "HidHide Configuration Client"
   3. Вкладка "Applications"
   4. Нажми кнопку "+"
   5. Откроется окно выбора файла.
      Внизу в поле "Имя файла" нажми Ctrl + V
   6. Нажми Enter

   ГОТОВО, если: в списке появился путь, который
                 заканчивается на wheel2pad.exe

   --- 6в. Спрятать руль ---

   1. Вкладка "Devices"
   2. Поставь галочку у своего руля
      (ищи слово Wheel, Racing, Artplays или Game controller)
   3. Внизу поставь галочку "Enable device hiding"
   4. Закрой HidHide

   ГОТОВО, если: ты снова запускаешь wheel2pad.exe
                 и окно пишет "Эмуляция запущена".


-----------------------------------------------------
[ ] ШАГ 7. Только если игра из Steam
-----------------------------------------------------

   1. Steam -> Библиотека
   2. Правой кнопкой по Forza Horizon 4 -> "Свойства"
   3. Раздел "Контроллер"
   4. Выбери "Отключить Steam Input"

   Игра из Microsoft Store / Xbox — пропусти шаг.

=====================================================
   ЧАСТЬ 2. КАК ИГРАТЬ (каждый раз)
=====================================================

   1. Двойной щелчок по wheel2pad.exe
   2. Чёрное окно СВЕРНИ (не закрывай!)
   3. Запусти игру
   4. Играй

   Закончила — закрой чёрное окно.

   В игре настройки управления НЕ меняй.
   Игра думает, что у тебя обычный геймпад Xbox.

   Удобно: правой кнопкой по wheel2pad.exe ->
   "Отправить" -> "Рабочий стол (создать ярлык)".
   Тогда запускать можно прямо с рабочего стола.
